# 03 F-5 路線一覧 (`/routes`)

ステータス: 未着手
依存: 00, 01
参照: 要件F-5、DESIGN.md §6.3 §5.5(表)
データ: `apps/web/data/routes_summary.json`(座標なしサマリー)

## スコープ

- Server Componentで routes_summary.json を読み、表を描画(ソートのみClient)
- 列: 判定・路線・事業者・距離・便数・累積上り・最急勾配・電費・往復使用率・日次電力量・追加充電回数・精度ランク(F-5-1)
- 任意列で並べ替え(F-5-2)。既定は日次kWh降順(DESIGN §6.3)
- CSVダウンロード(F-5-3)。クライアント生成でよい
- 行クリックで /routes/[id] へ
- フィルタ行(01の部品)

## 受入条件

- 色覚に依存せず全情報が読める(F-5-4)= 判定チップ+数値
- 最大幅1200px(DESIGN §4.1。データ密度の高いページの例外幅)
- 数値列は右寄せ + tabular-nums、表はコンテナ内横スクロール
- ページ本体は横スクロールしない
