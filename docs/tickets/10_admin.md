# 10 F-7 管理画面 (`/admin/*`)

ステータス: 未着手
依存: 06, 08
参照: 要件F-7 §5.3 §11-5/6、CLAUDE.md #4(Better Authは管理画面のみ)

## スコープ

- Better Auth導入(セッションはD1)。**一般利用者側には一切露出させない**
- BETTER_AUTH_SECRET は wrangler secret(登録はユーザー作業 — 要件§11-5)
- 管理者初期登録フロー(初回のみ — 要件§11-6)
- /admin 配下:
  - 車両マスタのCRUD(F-7-2)+ POST /api/admin/vehicles
  - バッチ実行状況・最終更新(F-7-3)+ GET /api/admin/batch
  - フィード期限切れ警告(F-8-5の表示側)
  - 判定しきい値の初期値変更(F-7-4)
- /admin/* と /api/admin/* 全体を認証で保護

## 受入条件

- 未認証で /admin・/api/admin にアクセスすると弾かれる
- 認証テーブルがDrizzleスキーマで管理されている
- シークレットがリポジトリに含まれない
- 一般画面のバンドルにBetter Authのクライアントコードが混入しない
