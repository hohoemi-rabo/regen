# 07 F-6 診断シナリオの保存・共有 (`/s/[id]`)

ステータス: 完了
依存: 05, 06
参照: 要件F-6 §5.3(セキュリティ)、DESIGN.md §10(印刷)

## スコープ

- POST /api/scenarios: 条件をD1に保存、推測困難ID(crypto.randomUUID等ベース、短縮可)を発行(F-6-1)
- **入力検証必須**: 認証がないため公開エンドポイント。型・値域・サイズ上限を検証(CLAUDE.md Server Actions節と同方針)。レート制限(要件§7)
- GET /api/scenarios/[id] + `/s/[id]` ページ: 同条件の診断を再現(F-6-2)
- 会員登録・個人情報なし(F-6-3)
- `/s/[id]` に noindex(検索エンジンに載せない — 要件§5.3)
- 印刷レイアウト: A4縦1枚、補助金申請に添付できる体裁(F-6-4、DESIGN §10)
- 05の「保存」ボタンを結線、発行URLのコピーUI

## 受入条件

- 不正なparams_json(巨大・型違い)が4xxで弾かれる
- IDが連番・推測可能でない
- 共有URLを開くと05と同じ結果が再現される
- 印刷に出典・生成日時・全仮定値が含まれる

## 実装メモ

- **保存するのは解決済みの値。** `params_json` に選択時点の車両スペック(重量・電池・CdA・効率・
  燃費・価格・出典URL・注記)と診断バンドル版を丸ごと控える。IDだけ保存すると、チケット10の管理画面で
  車両マスタを直したときに**補助金申請に添付した共有URLの数字が動いてしまう**ため。
  実測1.4KB、上限8KB。D1の車両マスタを書き換えても `/s/[id]` の数値が変わらないことを確認済み。
- **入力はそのまま保存しない。** `normalizeScenarioParams()` が既知のキーだけを取り出して組み直し、
  その正規形をD1に入れる。未知のキーや巨大な文字列は保存経路に入らない(テストで確認)。
- **検証ロジックは `packages/core/src/scenario.ts` に置いた。** apps/web にテスト基盤が無いため、
  UI非依存の純関数にしてユニットテストを書けるようにした(05の `simulate.ts` と同じ考え方)。26件追加、計86件。
- **共有IDは80ビット乱数のBase32 16文字**(例 `V1SF78WJMXNP60DQ`)。Crockford Base32 から
  紛らわしい `I/L/O/U` を除いてある(印刷物から書き写される可能性があるため)。連番でない。
- **レート制限はCloudflareのネイティブ機能**(`ratelimits` バインディング、IPあたり10件/60秒)。
  miniflareにローカル実装があるので `preview` でも効く。実測で10件目まで201・11件目から429、IP別に独立。
  **IPは制限キーに使うだけで保存しない**(F-6-3)。
- `/s/[id]` は **DESIGN.mdに画面設計節が無かった**ので §6.7 を新設した。読み取り専用・最大幅900px・
  結論→根拠→前提の順。車両A/Bは `.grid` を使わず flex で並べる(印刷CSSの `.grid` が5列固定のため)。
- 印刷でTCOグラフの2系列が白黒で潰れるので、**系列2を破線グレーにする規則を globals.css に追加**した。
- **比較画面への条件の復元(prefill)は入れていない。** `/compare` は46路線を静的プリレンダリング
  しており、`searchParams` を読むと全件が動的レンダリングに落ちるため。共有ページは記録に徹し、
  調整したい場合は比較画面を開き直す導線にした。
- **印刷の測定手順を是正した。** `--print-to-pdf` に `--virtual-time-budget` を付けないと
  フォント読み込みやストリーミングの前に印刷され、46路線のページ数が run ごとに 39〜43枚とぶれる。
  動的ルートではローディングのスケルトンだけが印刷されることもあった。
  待機して測った値が正で、診断書は **1枚39 / 2枚7**(CLAUDE.mdの元記載と一致)。
  チケット05・06に書いた「1枚40 / 2枚6」は待機なしの不正確な測定だったので注記を入れた。
- 検証: 保存→URL発行→クリップボードコピーまでCDPで実行し、`/s/[id]` の数値
  (電費0.85 / 往復49% / 追加充電3回 / 差14,938円/日 / 15年以内に逆転しない)が比較画面と完全一致。
  `/s/[id]` はA4縦1枚に収まり、出典・保存日時・全仮定値を含む。noindex を確認。375pxで横スクロールなし。
