# 09 F-4 実測補正「じぶん補正」 (`/calibrate`)

ステータス: 未着手
依存: 05(coreのブラウザ実行基盤)
参照: 要件F-4 §5.3、DESIGN.md §6.5、既存: packages/core/correction.ts

## 絶対条件(CLAUDE.md #5)

**CSVはサーバーに送らない。アップロード経路を作らない。** fetch/Server Action/Route HandlerにCSV内容を渡すコードを書かないこと。

## スコープ

- CSVドロップゾーン(File API、ブラウザ内パース)。列: 日付・走行距離・燃料/電力消費量(F-4-1)
- 「データは端末内でのみ処理され、送信されません」を枠内に常時表示(F-4-2、DESIGN §6.5)
- 推定値との突き合わせ → 車両効率・空調係数の補正(F-4-3)
- 補正前後の誤差を並べて表示(F-4-4)
- 係数はlocalStorageに保存し以後の診断(04/05)に適用。破棄ボタンあり(F-4-5)
- localStorage は try/catch で包み、読めない環境でも既定値で動作

## 受入条件

- ネットワークタブでCSV内容が一切送信されていないこと
- 不正CSV(列不足・数値でない)が明確なエラーメッセージで弾かれる
- 破棄すると即座に既定値へ戻る
