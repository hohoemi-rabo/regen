## スコープ

- packages/core をブラウザで直接実行(事前計算済みプロファイル入力 → 再計算)
- 車両マスタから2車種選択、左右比較(モバイル縦積み)(F-3-1)
- スライダー: 電池容量・車両重量・空調負荷・電力/軽油単価。**300ms以内に再計算反映**(F-3-2)
- TCO: 車両価格・補助金入力 → 損益分岐年数。グラフは横軸年・縦軸累計コスト・交点注記(F-3-3)
- 差分は数値で示す(「▼ 1,400円/日 安い」)
- 車両マスタ: まず `packages/core/vehicles.ts` の静的定義で開始(車種確定は要件§13-1)。06完了後にAPI取得へ差し替え
- 「この条件を保存」ボタンの置き場だけ用意(実体は07)

## 受入条件

- スライダー操作→表示更新が300ms以内(debounce可、体感で即時)
- 系列色は青(#2a78d6)×橙(#eb6834)のみ。3系列は作らない
- 変更中の仮定値がすべて画面に見えている
- 最大幅1200px(DESIGN §4.1。左右比較が窮屈にならない幅)

## 実装メモ

- **既存の `profiles.json` は再計算に使えない。** 表示用に最大400点へ間引いてあり `stepM` が
  25〜150mとばらつく(25mは46路線中8本のみ)。この配列で `energyForProfile()` を回すと冬電力量が
  最大1.55%ずれ、診断書と食い違う。そこで `seed-profiles` に
  **25m解像度の補正後標高 `apps/web/data/profiles25.json`**(小数2桁・266KB・38,332点)の出力を追加し、
  比較画面はこちらだけを使う。小数2桁の丸め誤差は冬電力量で最大0.012%(電費2桁・電池%整数の表示に影響なし)。
  実測で W1 / W0-1駒場線 / 阿智55.6km の3路線とも、電費・往復電池%・追加充電回数・判定が診断書と一致。
- **`packages/core` は追加のみでアルゴリズムは不変。** `vehicles.ts`(車両マスタ)と
  `simulate.ts`(`simulateVehicle` / `tcoSeries` / `breakEvenYear`)を新設。
  ゴールデンテスト47件は通過(新規13件を足して計60件)。
- **車両マスタ(要件§13-1)は実名4件。** 先頭の `standard-ev`(=§9.2の既定値)は診断書と同じ前提の基準車で、
  比較画面を開いた時点の数値が診断書と一致するように置いた。実名は BYD J6(2.0)/ BYD J7 / 日野ポンチョ。
  **CdA・転がり抵抗・駆動/回生効率はどのメーカーも公表していない**ため全車§9.2の既定値を流用し、
  BYD J7の車両重量とポンチョの燃費も非公表のため推定値であることを `note` に書いて画面に出している。
- **TCO(要件§13-5)は 車両価格 − 補助金 + エネルギー費のみ。** 整備費・充電器設置費・人件費・税保険は含めない。
  期間は15年。年間走行距離はダイヤ種別ラベルが46路線で31種類(「登校日9月・3月」「開館日」等)あり
  自動判別できないため、`片道距離 × 代表運行日の便数 × 年間運行日数(入力・既定250日)` とし画面で開示する。
  定価のない車種は価格0のままなので、その場合は「逆転しません」ではなく価格入力を促す。
- **スライダーの配置**: 空調負荷・電力単価・軽油単価は上部に共通(DESIGN §6.4)、
  電池容量・車両重量は車両固有なので各列に置き、車種を選び直すとその車種の値に戻る。
- **再計算は debounce しない。** 最長路線(2,226点)×2車両で中央値 **0.005ms**、
  スライダー操作からDOM更新まで実測 **33ms**(要求は300ms以内)。
- `chargingPlan()` は1便を走り切れない車両を表現できないため、`simulateVehicle` が先に成立性を判定し
  `infeasible` を返す。画面では充電計画を出さず必要kWhと使用可能kWhを示す。
- DESIGN.mdに §5.8 スライダー / §5.9 数値入力 / §5.10 折れ線比較グラフ(TCO)を追記した
  (どれも規定がなかった)。新しい色は足していない。
- 診断書の末尾から「車両を変えて試算する →」で遷移する。印刷は `print:hidden` 配下なので影響なし
  (46路線の印刷は悪化なし。当時記録した 1枚40 / 2枚6 は描画完了を待たない測り方によるもので、
  待機して測ると 1枚39 / 2枚7 — チケット07で手順を是正した)。
