# 02 F-1 EV適性マップ (`/`)

ステータス: 未着手
依存: 00, 01
参照: 要件F-1、DESIGN.md §6.1(画面) §7(地図スタイル)
データ: `data/seed/map_data.json`(46路線の診断結果+簡略ポリライン)

## スコープ

- MapLibre GL JS。Client Component + `next/dynamic`(`ssr: false`)
- ベースマップ: 地理院淡色タイル、彩度落とし(§7.2)、出典表記(§7.3)
- ポリライン: 白縁取り5px/55% + 判定色2.6px(§7.1)。選択中5px
- 凡例(左下浮動): ●▲■ + ラベル + 件数
- クリック→ポップアップ(路線名・事業者・km・便数・往復電池%・追加充電回数・診断書リンク)。モバイルは下部シート
- フィルタ行(事業者・判定・精度ランク)。絞り込んでも色は判定固定(§5.7)
- 初期表示は南信州全域に fitBounds(400ms)

## データの流れ

map_data.json は静的アセットとしてクライアントから取得する(RSC props渡しにしない — CLAUDE.md アンチパターン参照)。
将来バッチ(08)がR2配信に置き換えるが、本チケットではシードで完結させる。
