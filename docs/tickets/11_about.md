## 実装メモ

### 数字は1つも文章に書き写さない

ページ内の数値はすべて **`packages/core` の定数か D1 の実データ**から出す。
路線数・判定内訳・精度ランクA/Bの数・補正した路線数と合計距離・版・生成日はD1、
車両諸元・STEP・SMOOTH_W・MAX_GRADE・空調・単価・CO2係数はcore、
判定しきい値は **`getThresholds()`(D1の `settings`)** — 管理画面(F-7-4)で変えられるので
`DEFAULT_THRESHOLDS` を書くと画面と食い違う。
標高点の数も路線長 ÷ `STEP` から出している(文章に「数百点」と書かない)。

これを崩すと、要件§5.5(算出根拠を画面上で確認できること)がバッチ更新のたびに嘘になる。

### 印刷CSSは `.print-a4` を付けた画面にだけ効かせる

`globals.css` の `@media print` は、もともと全ページに
`.text-body { font-size: 8px }` / `main { max-width: none }` を掛けていた。
A4縦1枚に詰めるのは診断書(F-2)と共有シナリオ(F-6)だけの要件なので、
**圧縮のルールを `.print-a4` の下へ移し**、`DiagnosisSheet` と `ScenarioSheet` の
`<main>` にその印を付けた。読み物ページを本文8px・幅無制限で刷らないため。
分けたあとに46路線を測り直して 1枚39 / 2枚7 が変わらないことを確認済み。

### 図

- **46路線マップは `public/about/map.svg`(ベクタ)。** プロトタイプ
  `docs/prototype/南信州EV適性マップ_46路線.html` の中身が純粋なインラインSVGだったので、
  操作用の属性を落として書き出した(176KB / gzip 48KB)。
  **MapLibreの画面はヘッドレスで撮れない**(canvasが白く写る)ので、この形が唯一の自動化手段。
  紙にも出せる(`SvgFigure`)
- **処理の流れは `_components/PipelineDiagram.tsx`(自前SVG)。** `STEP` / `SMOOTH_W` /
  `MAX_GRADE` をcoreから読んで描くので、パラメータを変えると図も変わる。
  幅840のまま375pxへ縮めると文字が5pxになるため、図だけ `overflow-x-auto` + `min-w-[680px]`
- **画面写真3枚は本番から自動取得**(`sheet` / `compare` / `calibrate`)。
  紙では潰れるだけなので `Figure` は `print:hidden`
